# Companion and asset policy

This public repository intentionally contains no companion or character pack. Public builds start with an empty companion library and let each user import or create their own content.

The following are deliberately excluded from source control:

- private source material beneath `CompanionPacks/`;
- generated `.companionpack` files;
- generated build and installer artifacts beneath `Artifacts/`;
- imported user content and local application data.

The software licence in `LICENSE.md` applies only to material the licensor has the right to license. It does not grant rights to third-party characters, artwork, animation, fonts, audio, dialogue, or companion packs that users create or import. Contributors must not add such content unless they have documented permission to redistribute it under compatible terms.
