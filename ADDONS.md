# Desktop Familiar addons

Desktop Familiar supports optional addons. Read the [addon overview](docs/addons/overview.md) and [SDK compatibility contract](docs/addons/sdk-compatibility.md) before creating or changing an addon.

The current first-party addon is [Auto Clicker](docs/addons/auto-clicker.md). Its runtime, settings, hotkeys, input engine, target picker, and settings visual load only from its installed package. Third-party package sources are not supported yet.
